## 二、本版相对最终版1的关键变化

### 1. 草与吴昊阳的关系：从「删除」改为「实体碰撞」

| | 最终版1 | 最终版2（本版） |
|---|---|---|
| 模式 | `WU_GRASS_MODE = 'erase'` | **`'collide'`** |
| 分区图绿通道 | 禁区涂 `g = 0`（引擎自己不长草） | **原样保留**（引擎照常长草） |
| 草实例 | 清零（等同删除） | **一株不删**（30796 株） |
| 草与他的关系 | 靠「不存在」避免接触 | **顶点着色器「弯曲约束」**：草弯到接触他表面就停住 |

### 2. 实体碰撞的完整口径

- **碰撞体**：禁区 `grown` = 他身体轮廓 + 四周 `WU_CLEAR_MARGIN = 0.05 m` + 朝相机侧 `WU_CLEAR_MARGIN_CAM = 0.26 m`（886 格 ≈ 0.646 m²）
- **实体场纹理**（世界 XZ 线性映射，`592×579 @4 mm`）：
  - `R` = 有符号距离（体内为负，量程 ±0.16 m）
  - `G,B` = 外推方向（备用）
  - `A` = 恒 255（避 2D 画布预乘 alpha 把 RGB 清零）
  - **UV 必须翻转 v**：`v = 1 - (z-originZ)*invZ`（`CanvasTexture.flipY === true`，实测确认）
- **顶点着色器注入**（锚点 = 引擎算完 `myWorldPosition` 之后那一行）：
  1. 重算「不弯曲位置」= 把 `finalGrassInclination` 合成链里的**拨动**那一步撤掉（只留地形对齐 + 风），与引擎算法逐字同构
  2. 采样实体场得 `sdF`（当前顶点）/ `sdR`（不弯曲位置）/ `sdO`（草根）
  3. **弯曲约束**：`t = clamp((sdR - clear) / (sdR - sdF), 0, 1)`，`myWorldPosition = mix(wuRestPos, myWorldPosition, t)`
  4. **压住**：基座在禁区内 ⇒ `myWorldPosition = mix(myWorldPosition, grassOrigin, wuCrush)`（**整体收缩到根部**）
- **花同理**（同一张场，`gl_PointSize` 同步归零）

### 3. 关键参数

| 常量 | 值 | 含义 |
|---|---|---|
| `WU_BODY_COLLIDE` | `true` | 总开关；`false` = 回到删草旧行为 |
| `WU_BODY_CELL` | `0.004` | 实体场网格 4 mm |
| `WU_BODY_PAD` | `0.55` | 场覆盖范围 = 禁区包围盒外扩 |
| `WU_BODY_CLEAR` | `0.006` | 允许的最近距离（顶点不得进入体表 6 mm 内） |
| `WU_BODY_RANGE` | `0.16` | 有符号距离编码量程 |
| `WU_BODY_CRUSH` | `0.012` | 压住过渡：基座深入禁区 1.2 cm 以上 ⇒ 完全不可见 |
| `WU_GRASS_MODE` | `'collide'` | 草不删不移，只涂黄遮罩 |
| `WU_CLEAR_MARGIN` | `0.05` | 禁区四周外扩 |
| `WU_CLEAR_MARGIN_CAM` | `0.26` | 禁区朝相机侧额外扫掠 |

### 4. 必须记住的两个坑（都踩过、都已修）

1. **「只压平 y」≠「不可见」**：压平后草变成贴地的扁平草叶，从 23° 俯角看**仍然可见**，会把黄秃地整片盖住 ⇒ 用户看到「秃地没了」。必须**整体收缩到根部**（零面积、被光栅化丢弃）。
2. **采样 v 轴必须翻转**：场按「世界 z 从小到大」填画布**行**，而 `CanvasTexture.flipY = true` ⇒ 世界 z 小的一侧落在 v=1。少了 `1.0 - ` 采样在 z 方向就是镜像的。

| 接口 | 作用 |
|---|---|
| `__setBendAllowed(true)` | **放开鼠标拨动**（实验室默认钉死，不放开测不了拨动） |

| `__wuBodyField` | 看实体场参数 |
| `__wuBodySDAt(x, z)` | 采样任意世界点的有符号距离 |
