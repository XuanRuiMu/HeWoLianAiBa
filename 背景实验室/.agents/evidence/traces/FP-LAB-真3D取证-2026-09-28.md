# 真3D重做取证（2026-09-28，主代理亲测，全部来自运行中页面 evaluate）

结论：bundle 未把 three 挂到 window（window.THREE 为 undefined），但 scene 内 Mesh/ShaderMaterial 均可直接操作。
真3D重做不需要改 2.6MB bundle，只需在实验室 HTML 追加覆盖脚本，操作运行中的 scene 节点。

## 世界树（scene.traverse 实测）

- MainScene > CameraGroup > MainCamera；Experience 下：AnimeSky、DistantTerrainGround_0_0..3_3（16块）、DistantWater、Birds、MainIsland、TopIsland、ForestMotes、islands
- MainIsland（Mesh，BufferGeometry 2410 verts，bounds x[-0.62,0.7] y[-0.67,0.04] z[-1.13,0.81]，ShaderMaterial含 uGrassLightColor/uGrassDarkColor/uZonesTexture/uNoiseScale/uNoiseFrequency）
  - 子：east/west/south-waterfall、main-water、main-foam、main-island（地面本体）、main-portal-cave、trees、main-island-basalt、bushes001、campfire、crystals
- TopIsland 下 top 组：main-waterfall、top-island、basalt-top-old、tree-trunk-top、main001(top-water)、bushes（14簇，世界坐标已测）、floating-rocks（23块）、trees002（tree-008..011 共4棵真树）
- Grass_chunk_*（前景草实例块，pos 全 0，靠 instanceMatrix 定位）、Flowers、Foliage_chunk_*（trees 组 81 children 内）
- CampfireLight 世界坐标 (3.1,0.35,-0.4)；campfire-wood 11 根位于 (3.07~3.21, 0.12~0.18, -0.34~-0.20)
- 远景地面：PlaneGeometry 1089 verts x16，ShaderMaterial 25 uniforms（uWaterLevel/uRockLevel/uSnowLevel/uGrassColor系/uFog系/uTerrainAmplitude系）

## 天空/灯光（实测 keys）

- world.environment：animeSky（mainMaterial/dayMaterial/nightMaterial/mesh/celestialSync）、transition、currentConfig（preset/godrays #9bc2ff/animeSky mode day）、isNightMode
- world.light：mainLight/campfireLight/swarmPointLight/baseSunIntensity/rainSunMultiplier/lensflare/sunAnchor

## 真3D重做可行动作清单（全部已验证存在）

1. 重摆元素：trees002/tree-008..011、bushes/bush-foliage*、floating-rocks/basalt-floating-rock*、campfire 组均可 set position/rotation/scale
2. 地形重绘：main-island 材质 uniform（uGrassLightColor/uGrassDarkColor/uZonesTexture）可换色；2410 verts 可做顶点起伏（B版托举吴昊阳用）；远景 16 块 PlaneGeometry 可改 uGrassColor 系 + uTerrainAmplitude 系
3. 极光：AnimeSky mesh 之外新建独立天空挂件（ShaderMaterial 大面片跟随相机），不碰原天空材质
4. 吴昊阳趴草：新建透视地毯式 Mesh（CanvasTexture 贴 wu-2d.png，等比，铺在 main-island 前景坡面，随鼠标视差自然透视变化）+ 下方草块 bender 屏蔽（已有 inWuZone 思路，真3D版改为按世界坐标屏蔽）
5. 昼夜：沿用 setPhase + __grassOverride，金/紫配色保留

## A版失败根因（亲眼确认）

- canvas 经 drawImage 实测为空：WebGL 无 preserveDrawingBuffer，2D 回读为零；但 __experience/world/__dcm 全部就绪，3D 本体正常
- 失败不在 3D 本体，而在实验室覆盖层：SVG 远山/极光盖在 canvas 上但与 3D 透视无关，吴昊阳贴纸为 HTML 层，两者与鼠标视差幅度（0.015/0.009）不匹配，看起来就是"浮在上面"
- 字体/图片 404（orbitron/noise2）与 J9.ia.onerror 为 bundle 非 fetch 路径残留，不阻塞渲染
