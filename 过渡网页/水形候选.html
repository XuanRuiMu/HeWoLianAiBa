GitHub 现成的「液体 / 有机形状」过渡方案

下面每个都是从 GitHub 实际克隆下来、并在本机验证过能打开的项目，不是我自己画的。 点「看演示」直接看原作者的效果；「仓库」是它的源码出处。

OrganicShapeAnimationscodrops · SVG clipPath 有机形状

用不规则的有机形状做遮罩，形状本身在变形，把画面“咬”出来。 最接近你说的“水渍边界不规则地漫过去”。

看演示 仓库

CoverPageTransitioncodrops · 覆盖页过渡

一整块形状从一角生长、铺满全屏，再露出新页面。是“覆盖”而不是“位移”，结构最适合接进路由切换。

看演示 仓库

UnrevealEffectscodrops · clip-path 覆盖揭示

专门研究“覆盖元素 + clip-path”做页面切换，多个变体，边界形状多样。

看演示一 看演示二 看演示三 仓库

SuperfluidLayoutcodrops · 超流体

名字就是“超流体”，用文字块当图案做流转揭示，质感流动但形状是文字，不是水。

看演示 仓库

MorphingPageTransitioncodrops · 形状变形过渡

一条 SVG 路径变形为另一条，作为整屏过渡的形状骨架。

看演示 仓库

CreativeGooeyEffectscodrops · 黏稠融合

黏稠（gooey）质感的经典作品，圆与圆之间会“拉丝”融合。是液滴融合的参考底座。
