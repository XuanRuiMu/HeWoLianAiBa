# 任务交接 · 全屏三段过渡背景

## 一、原始需求（精简）

给「和我恋爱吧」做一个页面切换时的全屏过渡背景：

1. 画面沿斜线分成**三段**：左上、右下、中间
2. 三段**依次错开出现**，不是同时涌上来
3. 分界不能是笔直斜线，要丝滑、有流动感；整体好看、高端
4. 优先拿 GitHub 现成代码改造，不要从零写动画
5. 颜色、斜的角度都可以换

大体效果参考"C:\Users\xuanr\Desktop\玄锐暮工作区\和我恋爱吧\过渡网页\演示.png"，差不多是这样，需要更加艺术，更加现代化。

## 二、样品位置

`过渡网页/三段背景/` —— 就是原第五个候选「交错斜列」改成三段后的版本，共 6 个文件：
