## 二、接入步骤（3 步）

1. **复制模型**：把 `wu3d-pazi.glb` 复制为 `frontend/ceShiZiYuan/wu3d-pazi.glb`
2. **复制脚本**：把 `wu3D-ronghe.js` 复制为 `frontend/ceShiZiYuan/wu3D-ronghe.js`
3. **打补丁**：在 `和我恋爱吧/` 目录执行
   ```
   git apply 吴昊阳3D模型qwen3.8flash/wu3d-接入补丁.patch
   ```
   若补丁因另一 AI 同时改动 `grass-bg.html` 而失败，手动兜底：在 `frontend/public/grass-bg/grass-bg.html` 的 `</body>` 前加一行：
   ```html
   <script src="../ceShiZiYuan/wu3D-ronghe.js"></script>
   ```

已实测（2026-09-16）：`git apply --check` 通过；vite dev 对 `/ceShiZiYuan/*` 返回 200（该目录经 dev server 可直接访问，且不在 public/ 体积门禁内）。

## 三、运行行为与设计

- **同实例直挂**：真实登录页父页 THREE 为 r186（非 r128），引擎场景对象同为 r186，loader 解析的 `gltf.scene` 直接 `engine.scene.add`，吃引擎光照/后处理/阴影，与场景同色温。
- **前景遮挡**：角色为真实 3D 网格，深度测试自然被前景草遮挡。
- **接地阴影**：`castShadow/receiveShadow` 开启，由引擎平行光投影。
- **不抢交互**：所有角色网格 `raycast` 置空，不影响场景现有鼠标交互。
- **加载失败降级**：glb 加载失败/引擎未就绪 → 角色不进场景，背景与 T3 照常（符合"保留背景，不显示角色即可"）。
- **健康监测**：只记录被移除事件（`window.__wu3DaoLu='shiXiao:beiYiChu'`），不做重证明循环，避免 T3 已知的高频闪烁坑。

## 四、调参开关（无需改代码）

| 开关 | 作用 | 当前默认 |
|---|---|---|
| URL `?wu3d=0` | 禁用 3D 道路 | — |
| URL `?wu3dScale=` | 尺寸档位（0.70≈画面高 15%） | 0.70 |
| URL `?wu3dX/wu3dY/wu3dZ=` | 位置微调 | 4.93 / 0.61 / 2.98 |
| URL `?wu3dYaw=` | 朝向（250°=头朝画面右下，对齐 2D 基准） | 250 |
| `window.__wu3dGlb` | 覆盖 glb 地址（调试用） | `../ceShiZiYuan/wu3d-pazi.glb` |

**位置说明**：原候选锚点 (3.24, 2.77) 实测周围地形起伏大、地表隆起会埋没角色（曾表现为"只剩紫粉噪点"），定稿位置沿"相机→锚点"方向前移到画面下方近景带（2D 基准构图），y=0.61 为该处实测地表高度。**最终定稿请按截图目视微调。**

## 六、已知差异与后续建议

1. **昼夜**：登录页当前为夜景配色（紫粉草地），角色烘焙贴图自带白天色温，夜景下略偏亮。需求已定"通用一套配色"，如需夜景压暗可在 `wu3D-ronghe.js` 的材质遍历里按 `__caoDiPaiZhi` 调色温。
2. **手机细节**：手机为程序生成的深色圆角方块（2D 基准里也只是小黑块），如需更精致可在 Blender 里替换。
3. **眼镜**：黑框眼镜在 2D 烘焙贴图里有，模型头部尺寸下近景可辨、远景不明显。
4. 若另一 AI 已把 T3 平面方案改好，两套可共存（`?wu3d=0` 一键禁用本道路）。

## 七、回滚
