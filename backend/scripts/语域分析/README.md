# 语域分析脚本

这些脚本是**语域指标的复算工具**。它们只读已落盘数据，不调用任何外部 API。

## 为什么在这里（而不在 `.语料工作区/`）

`.语料工作区/` 被 `.gitignore` 排除（第三方语料原文不入库，见 AGENTS.md）。
若分析脚本也放在那里，**它们推导出的每个数字都无法被第三方复核** ——
本项目已因此多次出现「数字不可复算 → 结论作废」。故脚本入库，只有**语料原文**留在工作区。

若需运行，请先复制依赖到本目录，或在仓库根用等价路径调用。

## 口径纪律（血泪教训）

1. **LCCC 原文汉字之间有空格**（`"啊 我 好 爱…"`）。任何字符串匹配前**必须先剥空格**，
   否则 `startsWith('哈哈')` 恒为 0 —— 第十二轮曾因此得出「真人不使用哈哈」的错误结论。
2. **M2 目标值随会话长度变化**。`0.69%` 是 2 条发言的桶；25 轮对应 **16.1%**
   （见 `开场采样配置.ts:8` 的口径标注）。跨桶比较会得出错误结论。
3. **统计单位要与判据一致**。省略号类指标是**消息级**，M2 撞车是**轮级**，
   分子分母口径不同不能相除。
4. **簇级 vs 轮级**。16 个人设 × 25 轮不是 400 个独立样本；ICC≈0.165 → 名义 CI 低估约 2.2 倍。
