和我恋爱吧 · UI 重设计示例

以下为各页面的重设计方案可视化示例（静态 HTML，仅定方向，非最终实现）。请对照 UI与AI参数重设计-讨论.md 第 3、5 节，在文件中勾选你认可的方向。所有方案均刻意避开"深色玻璃拟态 + 蓝紫渐变"的 AI 模板。

主页（FP-02 · 双模式入口）必须 3 选 1

方案A · 微信原生拟态
像真的微信首页，角色作联系人卡片，温暖熟悉
方案B · 电影感视觉小说
满屏角色海报 + 衬线标题，高级交友 App 感
方案C · Gen-Z 俏皮纸感
纸纹 + 手绘贴纸 + 圆润展示体，浪漫俏皮

登录 / 注册（保留卷轴飞行动画）

方案A · 单屏沉浸式
满屏暖色天空花瓣，极简表单浮于底部面板
方案B · 信笺手写信
登录如展信，火漆印 + 衬线，浪漫可触

资料向导（1/2/3 步骤 · FP-03）

方案A · 对话式引导
TA 用气泡一步步问你，像真的在聊天
方案B · 极简步骤卡
竖向进度脊 + 强字体层级，一步一景

用户协议 / 隐私政策（协议模态框）

方案A · 舒适长读
衬线正文 + 顶部目录锚点，像读读库
方案B · 要点化
摘要 + 可折叠卡片，降低认知负载
