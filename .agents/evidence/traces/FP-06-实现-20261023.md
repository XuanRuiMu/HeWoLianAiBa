# FP-06 实现与验证（2026-10-23）

## 需求

- 需求 5：播放中的语音条必须与未播放时同一套三段弧形状，按音量只决定显示 1/2/3 段。
- 需求 6：暂停/停止按钮靠拢、缩小；整组与进度条间距约 8px。

## 改前事实（已核实）

- `QianDuan/src/components/聊天/语音气泡.vue` 旧实现把音量映射成三段各自的高度/透明度（`--laba-duan-N-gao/tou`），播放时弧线被非等比缩放与淡化，观感是“换了新弧线”，且任意音量下三段都可见。
- `QianDuan/src/composables/use语音音量.ts` 旧导出 `jiSuanYuYinDuanYangShi` 即该缩放/淡化映射。
- 控制行旧值：按钮 32px、图标 16px、热区 44px、行内间距 12px。

## 实现

### 段数逻辑（纯函数）

`QianDuan/src/composables/use语音音量.ts`

- 删除 `YU_YIN_DUAN_YANG_SHI_PEI_ZHI` 与 `jiSuanYuYinDuanYangShi`。
- 新增 `YuYinKeJianDuanShu = 1 | 2 | 3`、`YU_YIN_KE_JIAN_DUAN_SHU_PEI_ZHI`、`jiSuanYuYinKeJianDuanShu(biLi, shangCiDuanShu = 3)`。
- 迟滞门限（音量 0..1）：

| 上一档 | 升到 2 | 升到 3 | 降到 2 | 降到 1 |
| --- | --- | --- | --- | --- |
| 1 | ≥0.34 | ≥0.66 | - | <0.34 |
| 2 | - | ≥0.66 | ≥0.24 | <0.24 |
| 3 | - | - | ≥0.54 | <0.24 |

- `NaN`/`Infinity` 等非法值直接返回 3（无法分析音量时满三段）。
- 音量由既有 `duQuYuYinYinLiang()` 提供；降级时它返回 1，因此自然落到 3 段。

### 语音气泡

`QianDuan/src/components/聊天/语音气泡.vue`

- 模板：`laba-zu` 增加 `:class="keJianDuanShuLei"`，类名为 `laba-zu--1-duan` / `--2-duan` / `--3-duan`。
- 脚本：rAF 每帧只计算一次段数，且仅在段数变化时写 `keJianDuanShu` ref（单一 class）；播放结束、暂停、停止、组件卸载都归位 3 段；`prefers-reduced-motion` 下静态 3 段。
- 样式：删除全部 `scale/scaleY`、`--laba-duan-*`、旧 reduced-motion 覆盖；新增 `.laba-duan { transition: opacity var(--yuyin-duan-yin-cang-shi-chang) var(--quxian-biao-zhun); }` 与隐藏选择器：
  - 1 段：隐藏 `--2`、`--3`；
  - 2 段：隐藏 `--3`；
  - 3 段：无规则，全部显示。
- 未播放状态的 DOM、尺寸、颜色、描边与播放时完全相同，只有整段透明度在 80-120ms 内过渡。

### 紧凑按钮组

- 模板：两个按钮包进 `span.yuyin-kongzhi-zu`。
- 样式：`.yuyin-kongzhi-zu` 使用组内 `gap: var(--yuyin-kongzhi-jian-ju)`（3px）；`.yuyin-jindu-qu` 的 `gap` 从 12px 改为 `var(--jiange-xiao)`（8px）；按钮视觉 28px、图标 13px；`::before` 仍以 `inset: calc((视觉 - 热区) / 2)` 外扩，热区 36px（28 + 4×2）。
- 保留 `padding-inline: var(--jiange-13)` 与气泡内衬对齐、`margin-top: var(--jiange-xiao)`。

### 令牌

`QianDuan/src/styles/设计令牌.css` 仅改语音段：

- `--yuyin-kongzhi-chicun: 28px`（原 32px）
- `--yuyin-kongzhi-re-ku: 36px`（原 44px）
- `--yuyin-kongzhi-tubiao: 13px`（原 16px）
- 新增 `--yuyin-kongzhi-jian-ju: 3px`
- 新增 `--yuyin-duan-yin-cang-shi-chang: 100ms`
