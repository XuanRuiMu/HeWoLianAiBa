## 2. 根因修复口径（滚动条）

- 病灶：本环境 Chromium 走 Fluent 滚动条绘制路径，`::-webkit-scrollbar` 定制完全失效；
  `scrollbar-gutter: stable` 恒占约 15px 槽位挤压正文（"获取验证码"按钮被压）。
- 处置（登录内容.vue）：
  - `.biaodan-gundong` 删 `scrollbar-gutter: stable`，加标准属性 `scrollbar-width: none`；
    `.biaodan-gundong::-webkit-scrollbar { width: 0 }` 兜旧版 Chromium 双保险；
  - 保留旧 scrollbar-color/webkit 透明档文本：登录内容.test.ts 与 FP04a 仍在钉住它们
    （越界文件，本单不清），在 scrollbar-width:none 下两路径均不再绘制，属惰性文本；
  - overlay 滑块：外壳 `.gundong-waike`（position:relative; flex:1; min-height:0）承接原滚动口
    弹性位，滑块 `.gundong-huakuai` 绝对定位于外壳右缘（top:0、right:2px、宽 4px、圆角金条、
    pointer-events:none、aria-hidden）——不在滚动坐标系内，脚本只写小幅度 translateY，
    不随内容长距离位移（SimpleBar/OverlayScrollbars 同款结构，规避合成器滚动一帧滞后）。
  - 脚本（登录内容.vue 内，中文命名）：gengXinHuaKuai 按滚动比例写 height/transform
    （滑块高 = 视口高×(视口高/内容高)，最低 24px，命名常量）；内容不溢出 display:none；
    biaoJiHuaKuaiXianXing 滚动显形 + 静置 800ms 摘 xian-shi 淡出；chuLiGundongGunDong 为
    @scroll 入口。ResizeObserver 同时观察滚动口与 .biaodan-xingwei（覆盖窗口 resize、
    主题切换、切换动画期间 scrollHeight 连续变化、折叠/展开）；onBeforeUnmount disconnect
    + 清淡出定时器；ResizeObserver 以 typeof 守卫（jsdom/SSR 安全）。
  - 几何/颜色走令牌：--renzheng-gundong-huakuai-kuan:4px、--renzheng-gundong-huakuai-you-ju:2px
    （共用 :root）；--renzheng-gundong-huakuai-se 浅档 #a3813e（深金压象牙卡面）/深档 #d5b878
    （亮金压星夜卡面），取值与卡内既有强调金同源，成对无塌陷。
  - hover/focus-within 显形走 CSS（.gundong-waike:hover/.gundong-waike:focus-within）。
- 元素居中：移除 scrollbar-gutter 后验证码行不再被占位挤压；注册表单各行左右内边距本就对称
  （.shuru-zu 无水平 padding，字段通宽对齐卡内衬线），无需额外改动。

## 3. 出画动画口径

- variables.css：`--renzheng-qiehuan-weiyi` 32px（calc(--jiange-da + --jiange-xiao)）→ `110%`
  （translateX 百分比以滑动表单自身宽为基准，旧表单整体滑出可视区、新表单从另一侧整体入画，
  用户裁决"出画"语义）；`--renzheng-qiehuan-shi-chang` 0.65s → 0.5s（行程变长后与 0.45s
  网格行高度过渡保持连贯）。方向语义不变：you=旧出左/新从右入，zuo=反向；
  缓动保持既有 `--quxian-biao-zhun`（指令中 "--quxian-huan-ying 级别曲线" 按"保持现有曲线"
  执行，未换曲线——现状即 biao-zhun，换曲线超出用户点名范围）。减动效档仍整体归零。
