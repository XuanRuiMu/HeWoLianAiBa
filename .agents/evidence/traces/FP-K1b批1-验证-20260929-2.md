## 修正1【中·真实缺陷】滚动容器 `padding-top` 顶开 sticky 后代 —— 已复现 → 已修 → 已复验

### 1.1 缺陷机理
第 1 轮把 `.zhanji-liebiao` 改为 `padding: var(--jiange-zhong)`（上=16px）。该容器是滚动容器（`overflow-y:auto`），其内 `.zhanji-tishi`（`position:sticky;top:0;z-index:11`）与 `.zhanji-fenlei-biaoti`（`position:sticky;top:0;z-index:10`）是 sticky 后代。**sticky 的 `top:0` 是相对容器 padding-box 的**，容器一旦带上内边距，sticky 元素会被整体下推同样距离，滚动时其上方露出 16px 内容穿透带。改前 `padding-top=0` 故不触发。

### 1.2 复现（非空列表，先证真实存在）
`page.route` 拦截 `/战绩/分类`、`/战绩/列表` 返回 1 个默认分类 + 8 条假记录 → 渲染非空列表 → 滚动 300px：

| 量 | 未滚动 | 滚动 300px |
|---|---|---|
| `.zhanji-fenlei-biaoti` top | 227px | 68px |
| 容器 `.zhanji-liebiao` top | 52px（旧容器） | 52px |
| **sticky 顶 − 容器顶** | — | **16px**（= padding-top，穿透带宽度） |

截图 `K1b-sticky-复现-滚动.png`（可见标题下缘与首卡之间露出 16px 穿透带）。

### 1.3 修复（优先方案：上间距移出滚动容器）
```css
/* 改前 */ padding: var(--jiange-zhong);
/* 改后 */ margin-top: var(--jiange-zhong);
         padding: 0 var(--jiange-zhong) var(--jiange-zhong);
```
上间距改由容器自身 `margin` 承担（flex 列容器内 margin 不塌陷）；容器内 `padding-top` 归零，sticky 后代贴容器顶。

### 1.4 复验（深/浅 × 非空滚动 + 空态）
| 场景 | 容器 paddingTop | sticky 顶 − 容器顶（滚动 300px） | 判定 |
|---|---|---|---|
| 深色 · 非空 | `0px` | **0px** | 无穿透带 ✓ |
| 浅色 · 非空 | `0px` | **0px** | 无穿透带 ✓ |

截图 `K1b-sticky-修复后-滚动.png`（sticky 标题紧贴容器顶，无穿透带）。

对称性在修复后仍成立（见修正3 与 §浏览器实测）：上 = 容器 margin-top 16 + padding-top 0 = **16px**；下 = 标签栏 padding-bottom 4 + 列表 gap 12 + 空态卡 margin-top 0 = **16px**。

## 修正2【中·门禁漏洞】静态门禁三类漏网 —— 已改「先剥 var()/env() 再查残留长度」

### 2.1 旧门禁漏网（改前放行）
| 漏网类 | 反例 | 旧门禁为何放行 |
|---|---|---|
| ① 选择器与声明同行 | `.a { padding: 8px; }` | 依赖"属性必须在行首"，同行不匹配 |
| ② 含任一 `var()` 即整条豁免 | `.b { padding: calc(16px + var(--jiange-4)); }` | 只要值里出现 `var(` 就跳过整条 |
| ③ 多值混写 | `.c { gap: var(--jiange-xiao) 6px; }` | 同上，含 `var(` 即豁免，漏掉裸 `6px` |

### 2.2 新门禁实现（按属性名定位，不依赖行首）
1. `剥函数片段(值)`：按**括号配对**整段删除 `var(...)` / `env(...)`（支持嵌套），返回剩余串；
2. `裸长度(值)`：对剩余串匹配 `/\d+(?:\.\d+)?(?:px|rem|em)\b/`，命中即裸硬编码；
3. `扫间距声明文本(文本)`：规则级 `/([^{}]+)\{([^{}]*)\}/g` 切规则 → 声明级 `/(?:^|;)\s*([a-zA-Z-]+)\s*:\s*([^;]+)/g` 切声明 → 属性名命中 `/^(?:margin|padding|gap|row-gap|column-gap)(?:-[a-z]+)*$/` 才纳入；
4. 白名单（不判红）：`0` / `auto` / 百分比 / 视口单位（`vh/vw/vmin/vmax/dvh…`）——因剥离后剩余串里这些不含 `px/rem/em`。

### 2.3 合成反例自测（测试用例「静态门禁自证」）
| 输入 | 改前 | 改后 | 说明 |
|---|---|---|---|
| `.a { padding: 8px; }` | 放行 | **判红**（命中 `8px`） | ① |
| `.b { padding: calc(16px + var(--jiange-4)); }` | 放行 | **判红**（剥 var 后残留 `calc(16px + )`，命中 `16px`） | ② |
| `.c { gap: var(--jiange-xiao) 6px; }` | 放行 | **判红**（剥 var 后残留 ` 6px`，命中 `6px`） | ③ |
| `.d { padding: calc(var(--jiange-da) + var(--jiange-zhong)); }` | — | 放行 | 合法算式不误判 |
| `.e { gap: var(--jiange-12); }` | — | 放行 | 单令牌 |
| `.f { margin: 0 var(--jiange-4); }` | — | 放行 | 白名单 0 + 令牌 |
| `.g { padding: 0; }` | — | 放行 | 白名单 0 |
| `.h { margin-left: auto; }` | — | 放行 | 白名单 auto |
| `.i { padding: 12vh 50%; }` | — | 放行 | 视口单位 + 百分比 |

3 类反例改后全部判红、6 条合法写法零误判 → 用例通过。

## 修正3【低】对称断言只看第一条声明 —— 已改「多口径覆盖全部声明」

- `切上下文(样式)`：按顶层 `@media` 把 `<style>` 切成 `base` + 各媒体上下文（含条件文本）；
- `有效盒边(对们, 简写, 边)`：在给定声明序列下按**源码顺序**让 `padding` 简写与 `padding-top` 长属性互相覆盖，无声明视为 `0`；
- `盒边口径()` 返回 `{ base, 全并 }` 两口径（`全并` = base + 各 @media 依序覆盖，悲观口径）；
- 对称性断言改为在 **base 与 全并** 两口径下均断言：容器上内边距 = 0、空态卡上边距 = 0、**上 = 下 = 16px**；
- 另加独立用例：`.zhanji-liebiao` 在**任何**上下文（含媒体查询）内 `padding-top` 必须为 `'0'`——钉死修正1，防止回归。

（旧断言只读源码第一条 `padding` 声明，在 `@media(max-width:640px)` 内加 `padding-top:0` 覆盖仍会假绿；新实现下媒体覆盖会体现在 `全并` 口径。）
