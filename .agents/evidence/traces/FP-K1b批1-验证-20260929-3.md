## 修正A【中·真实假绿漏洞】选择器子串匹配 → 精确比较

- 位置：测试文件 `收集声明对` 的 `规则[1].includes(选择器片段)`。
- 机理：`.zhanji-liebiao-neirong`（过往战绩.vue:1698，含 `.zhanji-liebiao` 子串且源码更靠后）会污染"取末值"。
- 修复：按 `,` 切分 → trim → **全等比较**（`选择器们.includes(选择器片段)`）；复合/伪类选择器（`.zhanji-liebiao.tuo-zhuai-zhong`、`.zhanji-liebiao::-webkit-scrollbar-track`）不含间距声明，精确匹配后自然排除。

### 自测反例（模拟真实文件：`.zhanji-liebiao` gap=8px、`.zhanji-liebiao-neirong` gap=12px）
| | 读到 gap | 下间距 = 4+gap+0 | 判定 |
|---|---|---|---|
| 改前（子串 includes） | 12px（neirong） | 16px | **放行（假绿）** |
| 改后（精确匹配） | 8px | 12px | **判红**（上16/下12 不对称被抓） |

测试用例「门禁自证·修正A」：`收集声明对('.zhanji-liebiao { gap: 12px; } .zhanji-liebiao-neirong { gap: 99px; }', '.zhanji-liebiao', /^gap$/)` 长度 = 1、值 = 12px；复合/伪类选择器返回 `[]`。

## 修正D【低】断言对逻辑属性失明

- 修复：`有效盒边` 补逻辑属性映射（horizontal-tb + ltr）：`<简写>-block-start→top`、`-block-end→bottom`、`-inline-start→left`、`-inline-end→right`，以及双值简写 `<简写>-block` / `<简写>-inline`（start/end 分量）；同时把收集用属性族正则由 `(-[a-z]+)?` 放宽为 `(-[a-z]+)*`，否则 `padding-block-start` 根本不被收集。

### 自测反例
| 输入 | 改前 padding-top | 改后 padding-top |
|---|---|---|
| `padding-block-start: 16px` | `0` → **放行（假绿）** | `16px` → **判红** |

测试用例「门禁自证·修正D」：`padding-block-start:16px→top=16px`、`padding-block-end:8px→bottom=8px`、`padding-block:12px 6px→top=12px/bottom=6px`、`margin-inline-start:4px→left=4px`。

## 修正E【低】"margin 不塌陷"不变量无守护

- 上间距由 `.zhanji-liebiao` 的 `margin-top` 承担，成立依赖直接父级 `.zhanji-yemian` 是 flex 列（flex 项 margin 不塌陷）；父级改 `display:block` 则 margin 塌陷逃出、上间距失效而静态断言仍绿。
- 修复：新增用例显式断言 `.zhanji-yemian` 的 `display === 'flex'` 且 `flex-direction === 'column'`，把隐性不变量变显性。
- 自测反例：父级改 `display:block` → 新断言 `display=block ≠ flex` → **判红**（改前无此断言）。

## 修正F【低】门禁只扫首个 `<style>` 块

- 修复：`取样式` 由非贪婪 `exec`（只取首块）改为 `matchAll(/<style[^>]*>([\s\S]*?)<\/style>/g)` 取**全部**块并拼接后扫描。
- 自测反例：双 `<style>` 源，改前只取 1 块（第二块 `.b{margin:2px}` 被静默跳过，含 `.b`=false）；改后 2 块、含 `.b`=true（纳入扫描）。
