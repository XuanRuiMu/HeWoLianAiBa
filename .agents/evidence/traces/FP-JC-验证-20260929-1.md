# 第二轮（2026-09-29）：FP-I2 浏览器实测复核后修复

## 一、根因定位（与第一轮结论的关系）

第一轮声称"全部文字 ≥4.5:1"被证伪：FPD 断言读的是**源码**里的深色变量值，而浏览器里深色变量块**整体未生效**。像素取证（对 FP-I2-账号设置-深-21修复后.png 按区域聚类取笔画色）：

| 元素 | 实测笔画色 | 实为 |
|---|---|---|
| 用户名/统计数字/我的头像标题 | #2e2a22 系 | **浅色 --moSe #2e2a24** |
| 名片副标题/搜索设置/第一组胶囊/组标题/更换头像 | #2f4e37-#3d6b3d 系 | **浅色 --yeLvShen #3e6b3e** |
| 签名行/统计标签/UID | #635d57 系 | **浅色 --huiSe #6f695e** |
| 活跃标签"第一组·形象" | #904938 | 浅色 --taoTuShen #b85a3e |

即深色档整页在用浅色文字令牌，主代理清单六项全部由此解释。

**真正根因（编译器实验实锤）**：Vue SFC scoped 编译器会把 `:global(X) 后代` 形态的选择器**丢弃 :global() 之后的后代段**——

- 源码 `:global(:root[data-theme='dark']) .zhang-hao-an-quan { ... }`
- 编译产物 `:root[data-theme='dark'] { ... }`（`.zhang-hao-an-quan` 段消失）

深色变量因此落在文档根上，而页面自身 `.zhang-hao-an-quan[data-v-x]` 浅色变量块在同一元素就地重定义（元素自有定义胜过继承）→ 整页子树用浅色令牌。最小实验四种写法对比：`:global(X) .foo`→`X`（丢后代，错）；`:global(X .foo)`→`X .foo`（对）；普通 `[data-theme='dark'] .foo`→`[data-theme='dark'] .foo[data-v-x]`（对，采用此写法）。
