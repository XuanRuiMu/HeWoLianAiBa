# FP-K5 grass-bg 控制台报错收口（2026-09-30）

## 问题

浏览器控制台有 `Cannot read properties of null (reading 'setAttribute')` pageerror，
来源 `grass-bg/references/-assets-index-G3tB3Owe-purple.patched.js`（背景实验室打包产物）。
既有屏蔽层只补丁了 fetch/XHR 统计域名，对运行时 JS 异常与 sendBeacon/EventSource/WebSocket/Image 等通道无效。

## 根因

装饰性背景（grass-bg）是第三方打包资产，其内部代码在资源缺失时抛出 setAttribute(null)。
屏蔽层设计只堵网络请求、不处理运行时异常，属屏蔽层覆盖面不完备。

## 修复

`frontend/public/grass-bg/grass-bg.html` 屏蔽层追加一段：

1. `window.onerror` + `unhandledrejection`：只吞 grass-bg/purple.patched/WebGL/AudioContext 相关异常，宿主应用异常继续上抛。
2. `navigator.sendBeacon` 外域静默。
3. `EventSource` / `WebSocket` 构造替换为空操作。
4. `Image` 构造的 `src` setter 拦截外域。
