## 五、设计决策

1. **wenjian 分类严格按需求口径**：文本类=txt/md/markdown（2MB）、文档类=doc/docx/pdf/xls/xlsx/ppt/pptx/html/htm（10MB）。csv/json/归档/视频等未在需求列出的类型回落 wenjian 兜底 50MB。csv/json 虽为纯文本格式，但需求未将其列入文本类，遵循「禁止假设」不擅自归类。
2. **整卡 `<a>` 优于 div+click**：语义正确（中键/右键另存可用），与腾讯源码 @click="download" 行为等价但更符合 Web 标准。
3. **类型身份色是深浅恒等的固定色**（Word蓝/Excel绿/PPT橙红/PDF红/TXT灰），非主题色——文件类型识别色不随气泡主题变。
4. **下载箭头改装饰件**（aria-hidden）：热区由整卡承担，避免嵌套交互元素。

## 六、遗留

1. **csv/json 大小阈值归类待确认**：当前走 50MB 兜底。若产品认为应按文本 2MB 约束，需在 WEN_BEN_KUO_ZHAN 中补入。
2. **biaoqingshu 仍 10MB**：需求20 的「图片 20MB」按类别口径对应 tupian；表情包(biaoqingshu)未动（前端表情配置与后端同源测试均锁 10MB）。
3. **深浅双主题截图验证**：headless 模式无法截浏览器图，色值正确性仅代码级验证（全吃 CSS 变量）。
