# FP-02 实现与验证（2026-10-23）

## 需求

- 需求 2：普通模式第一二步的性别卡改为通用规则，选中卡按自身性别取填充、按对象性别取边框；自身未选按男性、对象未选按女性兜底。
- 需求 4 约束：个人资料的性别卡仍为专属规则（选中男=淡蓝填充+深蓝框，选中女=淡粉填充+深粉框），不得改动。
- 向导不得在挂载时用 `mo_ren_xing_bie` / `mu_biao_xing_bie` 回填，也不得自动跳到第 3 步；用户必须亲手点选前两步。
- 两步必须共用同一份配色逻辑，不得复制 CSS/常量。

## 改前事实（已核实）

- `QianDuan/src/views/资料设置向导.vue` 的 `onMounted` 会读取账号默认性别写入 `ziLiaoShuJu`，并在两者都存在时直接把步骤设为 3。
- 选中样式写死在 `.ziliao-kapian .xingBie-kaPian.beiXuanZhong[data-xuan-xing-bie=...]`，男卡恒为淡蓝+深蓝、女卡恒为淡粉+深粉，属个人资料专属规则。
- 第 2 步对象卡也套用同一份个人资料 CSS，未按“自身填充 + 对象描边”计算。
- `主页内容.vue` 跳转 `/profile-setup?moshi=putong`，向导不读 query，参数无消费者。
- 通用规则雏形在 `挑战主页.vue`：自身色填充 + 对象色深框。

## 实现

### 唯一色档解析

`QianDuan/src/utils/性别.ts`

- `解析性别框体色档` 增加可选第三参 `兜底色档`，默认 `'nan'`，既有两参调用行为不变。
- 对象档解析复用同一函数，传入 `'nv'` 作为兜底，不再另写一套。

### 通用组合函数（唯一真源）

`QianDuan/src/composables/use性别框体配色.ts`

- 新增 `使用通用性别框体配色({ 自身性别, 对象性别 })`，返回 `自身色档`、`对象色档`、`样式`。
- 淡色卡样式统一由内部 `组装选中样式(自身色档, 对象色档, 带光晕)` 产出；`使用默认性别卡配色` 与 `使用通用性别框体配色` 共用该函数，不再各自拼样式字符串。
- 样式：`backgroundColor` = 自身淡填充；`borderColor` = 对象深边框；`color` = 自身淡文字；`boxShadow` = 自身选中环。
- 自身未选 → `nan`；对象未选 → `nv`；不读取账号默认性别。

### 向导

`QianDuan/src/views/资料设置向导.vue`

- 删除整个挂载回填与自动跳步逻辑，删除 `使用用户仓库`、`解析主色档`、`解析性别`、`解析性别配色档`、`默认性别`、`默认对象性别`。
- 四个性别按钮统一绑定 `性别卡选中样式`（第 1 步 2 处、第 2 步 2 处，共 1 个脚本来源）。
- `主色档` 直接取通用组合的 `自身色档`，`对象勾选档` 直接取 `对象色档`；渣型文案同步用 `对象色档`。
- 增加步骤完整性守卫：持久化步骤超过“已选条件允许的最远步骤”时回退，例如步骤 3 但性别为空 → 第 1 步；只选自身 → 第 2 步；前两步齐全则保留第 3 步续接。
- 删除个人资料专属选中 CSS；卡内名称与 SVG 在选中时 `color: inherit`，继承自身性别文字色。
- 选中卡过渡增加 `background-color`，换选时填充平滑过渡。

### 死参数

`QianDuan/src/views/主页内容.vue`

- `router.push('/profile-setup?moshi=putong')` → `router.push('/profile-setup')`。

### 未改动

- `QianDuan/src/config/翻译表.ts` 未动。
