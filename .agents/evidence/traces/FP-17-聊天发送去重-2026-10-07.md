# FP-17 聊天发送重复根因修复 —— 证据与验证记录（2026-10-07）

## 任务与验收

聊天栏输入文本+图片，网络延迟下点击发送会重复发出同样消息；语音条（录音完成后等几秒才发送）
存在同类重复。要求：发送按钮/回车立即禁用或去重；前端生成幂等键交服务端幂等拒绝重复；
统一根因处理发送入口；运行 typecheck/lint/测试；浏览器慢网模拟验证不重复。

## 根因

1. **图文混排（主场景）**：`聊天页面.vue::faSongDaiFaTuWen` 修复前把发送中标志放在
   `await queRenTuPianShouQuan()` 之后；发送按钮 `:disabled="!keYiFaSong"` 不含任何发送中状态。
   授权等待/上传/投递窗口内按钮与回车可重复触发，每次在 `stores/聊天.ts::faSongTuWenXiaoXi`
   新建乐观气泡与一把**新**幂等键；服务端 `UNIQUE(用户ID,角色ID,幂等键)` 压不住不同键 ⇒ 重复消息。
2. **语音条**：`use录音.ts::wanChengLuYin` 无并发结算保护；真机 `pointerup` 与 `touchend`
   都绑 `songKaiLuYin`，两条结算链各取同一段录音 blob 各发一次。
3. **服务端幂等已存在**（本次未改后端）：`backend/src/services/消息.ts` 约 815-857 行
   `INSERT ... ON CONFLICT ("用户ID","角色ID","幂等键") DO NOTHING` + 回查本人用户消息原行；
   迁移 `032_FP09消息幂等键.sql` 建唯一约束；`utils/发件箱.ts::queDingMiDengJian` 钉稳定 UUID。

## 验证三态

- **通过**：`npm run typecheck`、`npm run lint` 全绿（frontend）。
- **通过**：前端全量测试 2226 过 / 2 失败；2 条失败均为改动前基线的既有用户 WIP
  （`src/__tests__/粘贴图片.test.ts` 两条，源起 `src/components/认证/出生日期选择器.vue`，与本次无关）。
- **通过**：浏览器慢网实测（真实 Chrome + vite dev + 模拟接口 4s 延迟，脚本在临时目录，
  截图落盘 `测试截图/`）：
  - 场景1 文本+图片慢网：在途按钮禁用=true；点击+回车+强制点击重复触发后 新增上传=1、新增消息=1、
    用户气泡=1、待发块清空；
  - 场景2 语音 pointerup+touchend 双释放：新增上传=1、新增消息=1（类型 yuYin）；
  - 场景3 失败注入（400）后整条重试：新增消息=2 且两次**幂等键完全相同**
    （`73a79f7e-…` 同键，服务端唯一约束可压重放）、成功后待发清空；
  - 白名单（仅场景3 故意 400 的两条）之外控制台错误=0。
- **变异自检（证明测试测得住）**：移除 `use录音` 闸门→双释放用例转红；闸门移到授权等待之后→
  授权窗口用例转红；移除入口闸门→直调用例转红；移除 store id 查重→同键收敛用例转红；
  浏览器脚本回退到旧实现→同脚本测到 4 条重复消息（4 上传/4 投递/4 气泡），修复后为 1。
