## 三、方案（两步走，先小后大）

### 第一步：出话层修正（当天可完成，用探针验证）

在不动架构的前提下改三处，每处配"改前/改后"探针对照（探针从新语料真实场景抽取，本地真模型跑）：

1. **长度锚**：把"短"从形容词变成可执行规则——"一般一条不超过 20 字；只有对方连续追问细节时才允许写长；写完检查，能删则删"。目标：中位长度从 14–22 压到 6–12。
2. **问号解禁（带形态限制）**：把"默认不带问号"改为"允许两种问号：确认推进（『那周六呢？』）与反问（『你呢？』）；仍然禁止连环追问与纯信息型追问"。目标：问号率从 2.6–4.8% 回到 10–14% 区间，且落在真人形态上。
3. **观点/咨询场景防展开**：补两条点名式约束——"对方抛观点时第一句只表态，不论证；对方问专业问题（护肤/健身/考试等），只说自己做过的，不给没问过的建议"。

验收：同一批探针（≥40 条，覆盖 14 场景）三臂对照（现状 / 只改长度 / 全改），逐条标注行为类别；问号率与长度中位作为退化检测，不作为优化目标。

### 第二步：机制补强（按用户批准范围执行）

按 FP-02 审计后仍成立的差距，优先级排序：

1. **记忆召回可视化**（Mirrai 已验证该形态）：AI 回复气泡下折叠展示"这轮想起了哪几条"，数据来自既有 关键事件/对话摘要/承诺兑现 三表，只加出参字段与前端折叠区。
2. **好感度四维独立展示 + 变化原因流**：`好感度变化历史` 表已存在，补出参与前端面板；对齐 Utsuwa 的多轴形态。
3. **定时主动关怀（最小版）**：在既有"沉默后追加"之上，按用户历史活跃时段采样，N 小时无互动发一条站内通知；不做推送通道。
4. **微信原生小表情拟真**（可选，视第一步效果）：Writer 输出受控的 `[表情名]` 标记，前端映射微信表情资源；这是新语料 14.5% 的高频特征，做成人无我有的拟真细节。
