你是一名表情包标注专员，任务是给「和我恋爱吧」项目的表情包图库做一次**全量重标注**：逐张打开图片、看图说话、重写标注、起对名字、剔除垃圾图。

## 一、工作目录与文件

- 图片目录：`和我恋爱吧/表情包/`（第一层，约 19,318 张，含 jpg/gif/png/webp）
- 已有 109 个 `wx_*.json`（微信原生小表情），这些图**保留原文件名**，但标注内容要按下方规范重写
- 你的输出：
  1. 每张保留的图 → 在图片目录生成**同名 `.json` 标注文件**（7 个字段）
  2. 判定剔除的图 → 把文件名追加到 `和我恋爱吧/表情包实验室/剔除清单.txt`（每行一个文件名，UTF-8）
  3. 需要改名的图 → 把图片文件改成「短名 + 原扩展名」，并同步生成「短名.json」
- 工作前先读一遍：`和我恋爱吧/表情包实验室/表情包标注规范-V2.md`（下称《规范》），**它定义了全部字段规则、情绪/风格/关系阶段白名单、剔除标准，冲突时以《规范》为准**

## 二、每张图的处理步骤

对每张图，依次做：

1. **打开图片，用视觉能力看清内容**：主体是什么（人/动物/黄脸/文字/场景）、有没有配字、动作表情是什么。
2. **判断类型**：
   - 正常表情包 → 进入第 3 步；
   - 命中《规范》第五节任一剔除条件（非表情包范畴 / 意义不明不知何时发 / 严重糊坏 / 色情血腥违规）→ 文件名追加到 `剔除清单.txt`，**跳过**，不产 JSON；
   - 粗口/沙雕/阴阳怪气但属于正常网络梗文化 → **不算违规，保留**。
3. **重写 7 字段**（全部中文，一个不能漏）：
   - `短名`：≤30 字符、全库唯一、无 `[]【】::`、中文短句，结构「主体+动作/情绪」；图上如果有经典配字要体现（如「雨女无瓜」「退退退」）
   - `描述`：≤120 字符，写清「图上有什么 + 配字是什么 + 替哪句话」
   - `情绪标签`：只能从 12 个里选 1 个 —— `好笑 / 感动 / 无语 / 赞同 / 撒娇 / 安慰 / 庆祝 / 破冰 / 告别 / 卖萌 / 生气 / 委屈`（口诀：这张图替 AI 说哪句话）
   - `适用场景`：≤120 字符，具体到聊天语境（如「对方说晚安时」「被夸时」「自己说错话时」），禁止写「任何场合」这种空话
   - `启用`：一律 `true`
   - `风格`：只能从 4 个里选 1 个 —— `黄脸 / 祝福 / 日常 / 梗图`（黄脸=小黄脸/emoji；祝福=风景花朵+大字祝福；日常=温和生活贴图；梗图=熊猫头/金馆长/暴漫/拼贴/大字喊话/沙雕）
   - `关系阶段下限`：默认 `认识`；只有亲亲/爱心/暧昧挑逗→`暧昧`；粗口/性暗示/重口→`心动`；情侣私密梗→`热恋`（宁低勿高）
4. **决定文件名**：
   - `wx_` 开头的 109 个原生表情 → **文件名不动**；
   - 旧名本来就是干净贴切的中文短名（≤15 字、无乱码、无站点残留）→ **文件名不动**；
   - 文件名是编号/乱码/下载站残留（如 `IMG_1234`、`mmexport123`、`xxx表情包大全 2.jpg`）/与图意不符/超长 → 改为「短名 + 原扩展名」，短名撞名时加序号（`熊猫头摊手2`）。
5. **写输出**：把 JSON 写到 `表情包/<短名或原主名>.json`（UTF-8，格式见下），改名则同时重命名图片文件。
6. 每处理 200 张，输出一次进度：已处理 X / 共 19318，其中产出 JSON A 条、改名 B 条、剔除 C 条。

JSON 格式（严格照抄，不要加字段）：

```json
{
  "短名": "熊猫头摊手",
  "描述": "熊猫头无奈摊手，配字'我也没办法'，用来接没辙的场面",
  "情绪标签": "无语",
  "适用场景": "对方说了让人接不下去的话时垫场；自己被将住时用来自嘲",
  "启用": true,
  "风格": "梗图",
  "关系阶段下限": "认识"
}
```

## 三、质量红线（违反则本条作废重做）

1. **必须逐张实际看图**，禁止只读文件名或旧 JSON 猜内容。
2. **禁止情绪标签偷懒全标一个**。旧库 1.4 万/1.9 万条全标「无语」是反面教材；全库分布应大致符合真实聊天：好笑/赞同/卖萌/安慰/破冰 占大头，无语/生气/委屈/告别 是少数（无语占比控制在 15% 以下）。
3. **描述和场景必须具体**，禁止「微信原生表情：xx」式套话、禁止「任何场合都能用」式空话。
4. **短名全库唯一**，撞名按规则加序号；禁含 `[ ] 【 】 : ：` 和换行。
5. **只改名不改图**：不允许裁剪、转码、覆盖图片内容。
6. 剔除清单里**只写文件名**，不写路径；剔除的图不写 JSON。
